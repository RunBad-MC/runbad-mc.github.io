🌾 Getting Started

Welcome to The Pantry! Here's a five-step flow to get you settled in. Everything here is also available in-game — look for the /command next to each step.

Prefer to browse in-game? Run /quickstart to open this same flow as a menu.

Looking for ranks instead? Jump straight to Ranks.

1. Protect Your Base

Learn how to claim and protect your stuff so nobody can grief your builds. See the Claims Guide, or run /claimsguide in-game.

2. Catch a Critter

A fun mechanic — craft a Critter Catcher and turn mobs into spawn eggs. See the Critter Catcher Tutorial, or run /crittercatcher in-game.

3. Pick a Chat Tag

Customize how you show up in chat with a fun tag. Run /tags in-game to pick one.

4. Join the Discord

Hang out with other Beans outside the server too. See the Discord Linking Guide, or run /discord link in-game.

5. See Everything Else

Your profile, kits, RTP, the Pride collection, and more all live in the main menu — run /menu in-game.

  • Your Profile: view/edit your bio, favorites, and preferences with /profile.
  • Pronouns: set how the server refers to you with /pronouns.
  • Pride Collection: browse pride flags and decor to place around the server — open /menu and look for Pride Collection.

Quick Settings & Handy Commands

Things you'll want whenever, not just on day one.

  • Toggle Phantoms — /nophantoms toggle. Phantoms getting annoying? Turn them off for yourself (or back on) any time.
  • Worlds & Random Teleport — see the Worlds Guide, or run /rtp in-game.
  • Server Rules — take another look whenever you need to, on the Rules page.
  • Privacy Settings — control who can DM, TPA, pay, or gift you, and your map visibility, with /priv.
